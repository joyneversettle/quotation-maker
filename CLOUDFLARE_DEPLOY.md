# Cloudflare Pages deployment

## Build
1. Install Node.js 20+ (Node 22 recommended).
2. Run `npm install`.
3. Run `npm run build`.
4. Cloudflare Pages output directory: `dist`.

## Cloudflare Pages dashboard
- Framework preset: Vite
- Build command: `npm run build`
- Build output directory: `dist`
- Node version: 22

For drag-and-drop deployment, build the project first and upload the generated `dist` folder.
